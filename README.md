# Proyecto-Web-Ejemplo

Proyecto web desarrollado con HTML y CSS para practicar Git y GitHub.

## Cómo clonar y ejecutar el proyecto

Para clonar el repositorio:

    git clone https://github.com/ChoMzo/Proyecto-Web-Ejemplo.git

Entrar en la carpeta:

    cd Proyecto-Web-Ejemplo

Para ejecutar el proyecto, abrir el archivo `index.html` en un navegador web.

## Ramas del proyecto

### main

Contiene la versión principal y estable del proyecto web.

### feature-mejora-estilo

Rama utilizada para realizar mejoras en el diseño y la presentación visual de la página mediante cambios en `style.css`.

Los cambios de esta rama fueron integrados posteriormente en `main` después de resolver un conflicto de merge.
